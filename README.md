# DSA Practice Log (Java)

CLI to track LeetCode-style problems by **pattern** and **difficulty**, with simple spaced-repetition (`due` command).

## Run

```bash
mvn test
mvn package
java -jar target/dsa-practice-log-1.0.0.jar add "Two Sum" hash-map easy
java -jar target/dsa-practice-log-1.0.0.jar list
java -jar target/dsa-practice-log-1.0.0.jar due
